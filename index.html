🎨 Automatic Game Theme

The website automatically recognizes the selected game's filename and picks a matching color palette and icon. FireRed goes red, Sapphire goes blue, Emerald goes green, and other games get their own consistent color.

Add .gba files and optional matching .ico icons to the repository root or games/ folder. On a push to main, GitHub Actions runs node generate-library.cjs and publishes the updated library to GitHub Pages. In repository Settings → Pages, set Source to GitHub Actions.

Save Manager

📤 Back Up Your Save

First save normally through the game's menu. Then download a copy of your save data for safekeeping.

📥 Import a Save

Supports regular .sav and .srm files, plus compatible EmulatorJS .state files.

✓ Save Imported Successfully!

Your save is ready. Just restart the emulated game to load it.

  1. Close this Save Manager.
  2. Select Restart in the EmulatorJS toolbar.
  3. Choose Continue on the Pokémon title screen.

Avoid saving the currently running game before restarting.

💾 Save States

Save states are snapshots of the emulator. The built-in toolbar provides Save State, Load State, Quick Save and Quick Load.

A save state from another emulator may not be compatible. Regular Pokémon saves are generally better for transferring progress.
