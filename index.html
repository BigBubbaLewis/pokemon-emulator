Save Manager

📥 Import a Save

Import a regular game save (.sav or .srm) or a compatible EmulatorJS save state (.state).

⚠️ SAVE IMPORTED — RESTART REQUIRED!

Your imported save will NOT automatically appear in your currently running game.

You MUST restart the emulated game using the EmulatorJS Restart button.

After restarting, choose CONTINUE on the game's main menu.

DO NOT save your current game before restarting, or you could overwrite the imported progress.

📤 Export a Save

Save normally inside your Pokémon game first, then export your backup.

💾 Save States

Save states are instant snapshots. Use the built-in Save State, Load State, Quick Save and Quick Load controls.

States created by another emulator may not be compatible with EmulatorJS.
