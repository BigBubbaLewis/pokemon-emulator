✓ Save Imported Successfully!

Your save is ready. Just restart the emulated game to load it.

  1. Close this Save Manager.
  2. Select Restart in the EmulatorJS toolbar.
  3. Choose Continue on the Pokémon title screen.

Avoid saving the currently running game before restarting.

💾 Save States

Save states are snapshots of the emulator. The built-in toolbar provides Save State, Load State, Quick Save and Quick Load.

A save state from another emulator may not be compatible. Regular Pokémon saves are generally better for transferring progress.
