Save Manager

Regular game saves (.sav / .srm)

These are made by selecting SAVE inside Pokémon Emerald. To import an existing regular save, use the EmulatorJS toolbar inside the game and select Load Save Files. To download a backup, use Save Save Files. After importing, restart the game from the emulator toolbar, then choose Continue.

Always back up your current save before importing another one. Make sure the save belongs to the same game.

Emulator snapshots (.state)

These are instant snapshots, not ordinary Pokémon saves. Use the emulator's Save State / Load State controls for these. A standalone mGBA save state may not be compatible with EmulatorJS.

Is import failing?

Check whether your file ends in .sav, .srm, or .state, and whether it came from mGBA or this website. Those details determine the correct import method.

This manager uses the emulator's built-in import/export tools rather than replacing them with an incompatible file loader.

GBA Game Library
